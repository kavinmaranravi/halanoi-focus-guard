# Contributing to Halanoi Focus Guard 🛡️

Thank you for your interest in contributing to **Halanoi Focus Guard**! We welcome community contributions to make this extension faster, smarter, and more reliable for everyone.

---

## 📋 How to Contribute

- 🐛 **Report Issues**: Found a bug or website bypass? [Open an Issue](https://github.com/kavinmaranravi/halanoi-focus-guard/issues) with the site URL, browser version, and console logs.
- 💡 **Suggest Features**: Have an idea for improved filtering, UI enhancements, or AI heuristics? Create a feature suggestion issue.
- 💻 **Submit Code**: Pick an open issue or suggest a PR.

---

## ⚡ Development & Setup

### Loading the Unpacked Extension in Chrome:
1. Fork and clone this repository:
   ```bash
   git clone https://github.com/<your-username>/halanoi-focus-guard.git
   cd halanoi-focus-guard
   ```
2. Open Google Chrome (or Microsoft Edge) and navigate to `chrome://extensions/` (or `edge://extensions/`).
3. Toggle on **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the cloned folder.
5. Make your code changes in `popup.js`, `content.js`, or `background.js`.
6. Click the **Reload** (circular arrow) icon on the extension card in `chrome://extensions/` to test your updates.

---

## 🌿 Pull Request Process

1. Create a descriptive feature branch:
   ```bash
   git checkout -b feature/my-new-feature
   ```
2. Keep changes clean, minimal, and well-tested across Chromium-based browsers.
3. Open a Pull Request with a clear description of changes and test steps.
